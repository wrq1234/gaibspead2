# GAIB Spread Monitor (Bitget ↔ Kraken Arbitrage)

Односторінковий веб-додаток у стилі dark crypto trading dashboard для моніторингу спреду та реальних арбітражних можливостей між біржами **Bitget** та **Kraken**.

---

## 🚀 Покрокова інструкція запуску (без знань програмування)

### КРОК 1: Налаштування Telegram Бота
1. Відкрийте Telegram і знайдіть бота **@BotFather**.
2. Надішліть команду `/newbot`, придумайте назву та username для бота.
3. BotFather надасть вам **Bot Token** (виглядає приблизно так: `7123456789:AAFxxxxxxxxx...`). **Збережіть його в надійному місці і нікому не передавайте!**
4. Знайдіть у Telegram бота **@userinfobot** і надішліть йому будь-яке повідомлення. Він відповість вашим **Chat ID** (наприклад, `987654321`).
5. Знайдіть вашого нового бота в Telegram та натисніть **Start** / `/start` (це обов'язково, щоб бот мав дозвіл надсилати вам повідомлення).

---

### КРОК 2: Публікація коду на GitHub
1. Зареєструйтесь або увійдіть на [GitHub.com](https://github.com).
2. Натисніть кнопку **New Repository** (Створити новий репозиторій).
3. Назвіть репозиторій `gaib-spread-monitor`, виберіть **Public** і натисніть **Create repository**.
4. Завантажте всі файли з цього проєкту (`index.html`, `style.css`, `app.js`, `config.js`, `README.md`, `.gitignore`, та папку `api/`) у ваш репозиторій через кнопку **Add file ➔ Upload files**.

---

### КРОК 3: Увімкнення безкоштовного GitHub Pages (Frontend)
1. У вашому GitHub репозиторії перейдіть у **Settings** ➔ розділ **Pages** (у лівому меню).
2. У блоці **Build and deployment** під пунктом **Source** виберіть **Deploy from a branch**.
3. Вкажіть гілку **main** (або `master`), папку `/(root)` і натисніть **Save**.
4. Зачекайте 1-2 хвилини. Оновіть сторінку і ви отримаєте ваше готове посилання на сайт (наприклад, `https://yourusername.github.io/gaib-spread-monitor/`).

---

### КРОК 4: Безкоштовний деплой Serverless Backend (Vercel)
Для безпеки **Token бота не має бути у фронтенді**. Тому ми безкоштовно розгортаємо міні-сервер Vercel:

1. Перейдіть на [Vercel.com](https://vercel.com) та увійдіть через ваш **GitHub акаунт**.
2. Натисніть **Add New ➔ Project**.
3. Виберіть ваш репозиторій `gaib-spread-monitor` і натисніть **Import**.
4. У формі налаштувань знайдіть блок **Environment Variables** (Змінні оточення):
   - **Key:** `TELEGRAM_BOT_TOKEN`
   - **Value:** вставте Token від BotFather (отриманий на Кроці 1).
5. Натисніть **Deploy**.
6. Через 20 секунд Vercel видасть вам посилання на проект (наприклад, `https://gaib-spread-monitor.vercel.app`).
7. Ваша сереверлесс-функція буде доступна за адресою:  
   `https://gaib-spread-monitor.vercel.app/api/telegram`
